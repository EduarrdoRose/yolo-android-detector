# YOLO Android Detector (Kotlin + CameraX + ONNX Runtime)

This project is a full Android Studio scaffold for real-time object detection using YOLOv8 ONNX.

## Important
`app/src/main/assets/yolov8n.onnx` is a placeholder file. Replace it with an actual exported YOLOv8 ONNX model.

## Build
Open in Android Studio (JDK 17, Android Gradle Plugin 8.4.2) and sync.
